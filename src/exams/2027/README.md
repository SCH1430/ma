# Проекты демоверсий ФИПИ 2027

Дата проверки источников: 1 ноября 2026 года. На официальных страницах ФИПИ
эти документы обозначены как **проекты**. Статус сохраняется в приложении;
окончательное утверждение из даты публикации не предполагается.

- [ОГЭ: официальная страница](https://fipi.ru/oge/demoversii-specifikacii-kodifikatory)
- [ЕГЭ: официальная страница](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory)

Скачанные архивы и неизменённые PDF находятся в `sources/`. Их URL и SHA-256
зафиксированы в `sources/index.json`, `manifest.json` и `difficulty.json`.
PNG в `images/` получены точным рендерингом областей исходных PDF, без
перерисовки условий или формул. Координаты измеряются в PDF points сверху слева.

Сохранены все примеры, разделённые в оригиналах словом «ИЛИ»: 25 в ОГЭ,
80 в базовом ЕГЭ и 49 в профильном ЕГЭ. Профильный проект 2027 содержит
20 номеров; краткие ответы относятся к номерам 1–13. Все допустимые варианты
из каждой ячейки официальной таблицы ответов принимаются независимо.
Развёрнутые решения проверяются по исходным критериям самостоятельно.

Идентификаторы нового сезона имеют вид `exam-2027-oge-1-1`.
Сезон 2026 и его идентификаторы не изменены. В каталоге экзаменов у архива
сохранены `oge`, `ege-basic`, `ege-profile`, а у проектов добавлен суффикс
`-2027`. Поле `baseExamId` связывает типы экзаменов разных лет.

Для повторного импорта сохранённых PDF нужны `pdfplumber`, Pillow и Poppler:

```sh
PDFTOPPM=/path/to/pdftoppm python scripts/import_exam_2027.py
python scripts/validate_exam_seasons.py --sources
```

Обычная сборка использует только сохранённые JSON, PNG и PDF и не обращается
к сети. Источники 2026 при повторном импорте нового сезона не перезаписываются.
