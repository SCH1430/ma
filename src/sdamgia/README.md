# Подборка «Решу ЕГЭ / Решу ОГЭ»

`bank.json` хранит 200 заданий из 25 подтипов: 96 заданий профильного
ЕГЭ, 40 базового ЕГЭ и 64 ОГЭ. В каждом подтипе восемь задач. Это отдельный
источник, а не часть авторского банка и не официальная демоверсия ФИПИ.

У каждой задачи сохранены исходный номер и ссылка `problem?id=…`, ответ
источника, SHA-256 полученной страницы, дата отбора, условие и решение.
Номера типов относятся к каталогу источника на 26 октября 2026 года;
они не объявляются нумерацией конкретной спецификации ФИПИ.

`promptHtml`, `solutionHtml` и `answerHtml` содержат только разрешённые
теги; формулы и рисунки встроены как локальные data URL. `prompt` и
`solution` сохраняют текст для поиска и доступности, включая описания
формул из атрибутов `alt`. Для печати подготовлены `printImages`,
`solutionImages` и `answerImages`: изображения PNG с сохранением формул.
Развёрнутые решения проверяются человеком по образцу и критериям проекта.

## Обновление подборки

Обычная сборка читает готовый JSON и не обращается к сети. Для отдельного
повторного импорта нужен Python с `lxml`:

```sh
python scripts/import_sdamgia.py
```

Импортёр выбирает решённые прототипы с нескольких страниц каталога.
Если в подтипе их недостаточно, рассматривается ограниченный список
аналогов источника. Страницы, где вместо решения приведён прототип с
другими числами, отклоняются. Ответ проверяется по ключу исходной страницы;
это не заявление о независимой математической экспертизе всех решений.
Исходные ответы HTTP кешируются в игнорируемой папке
`preview/sdamgia-cache/`; итог отбора — `import-report.json`.

Затем подготовьте PNG. Для этой отдельной операции нужны Node.js,
`playwright`, `sharp` и установленный браузер Chromium или Edge:

```sh
node src/sdamgia/render.cjs
python scripts/sdamgia_assets.py
python scripts/build.py
```

Путь браузера можно задать переменной `BROWSER_EXECUTABLE`; по умолчанию
используется стандартный путь Edge в Windows. `NODE_PATH` при необходимости
указывает на каталог установленных пакетов. Зависимости импорта и
растеризации не нужны для работы сайта и обычной сборки.

Растеризатор блокирует любые сетевые запросы. Он сохраняет промежуточные
результаты отдельно в `preview/sdamgia-rendered.json`, затем добавляет их
в JSON банка. Кеш связан с SHA-256 всех трёх HTML-фрагментов: изменение
условия, решения или ответа требует повторной растеризации. Обычная
сборка также проверяет этот отпечаток. `--watch` позволяет запустить его параллельно с импортом:
слияние выполняется после появления всех 200 задач. `--force` пересоздаёт
PNG вместо использования кеша. Перед проверкой и публикационной сборкой
необходимо дождаться завершения обеих команд.
