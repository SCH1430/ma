# БАЗА — пространство математики школы 1430

Для запуска откройте `index.html` в браузере. Страница содержит банк заданий,
стили, скрипты и средства создания PDF; подключение к интернету для работы не нужно.

## Структура

- `index.html` — готовая автономная страница.
- `src/` — интерфейс, исходный банк заданий, библиотеки и их лицензии.
- `scripts/` — сборка и проверки.
- `checks/` — данные ручных проверок, вспомогательные проверки и тестовые примеры.

В интерфейсе усилен контраст карточек и текста, основные действия выделены зелёным.
Разделы отмечены иконками, четыре ступени сложности — цветными метками с подписями
и индикатором из полосок. Рабочие заголовки, отступы и фильтры сделаны компактнее.
После верного ответа основной акцент переходит на кнопку следующего задания.
Проверены ученический и учительский режимы, узкий экран, планшетная и широкая сетки.

## Сборка и проверка

Выполняйте команды из папки `БАЗА`. Для сборки нужен Python 3.10 или новее;
для JavaScript-проверок — Node.js. Устанавливать сторонние пакеты не требуется.

```sh
python3 -B scripts/build.py
python3 -B scripts/validate_bank.py
node scripts/validate_runtime.cjs
node scripts/validate_font.cjs
```

Сборка обновляет `index.html`, создаёт `checks/bank.json`, `checks/oracles.json`
и отчёт `checks/semantic-results.json`. Поэтому проверки запускаются после сборки.

Для полной проверки экспорта PDF:

```sh
node scripts/export_and_audit.cjs
```

Дополнительные проверки авторских банков и смысловых повторов:

```sh
python3 -B checks/check_67.py
python3 -B checks/check_author_89.py
python3 -B scripts/semantic_audit.py
python3 -B checks/audit_67.py
python3 -B checks/audit_author_89.py
```

Локальные `audit_*.py` выводят кандидатов на сходство без учёта ручных решений;
итог с объединениями и актуальными ревью находится в `checks/semantic-results.json`.
Браузерные сценарии `scripts/cua-qa.js` требуют активной сессии CUA и открытой
страницы; они не запускаются напрямую через Node.js.

Тестовые PDF в `output/`, снимки экрана в `preview/` и кэш `__pycache__/`
не требуются для запуска. Сгенерированные отчёты можно удалить после проверки.
Сохраняйте исходники и данные ручных проверок в `checks/`, в частности
`property-reviews*.json`, `semantic-reviews.json` и `semantic-groups-*.json`:
они участвуют в проверке ответов и подсчёте независимых задач.
